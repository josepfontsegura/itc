Resit exam 2026

Problem 1. A binary symmetric channel with crossover probability $\tfrac15$ receives as input either $00$, with probability $\tfrac13$, or $11$, with probability $\tfrac23$. Each of the two bits is passed through the channel independently. What is the probability that the second output bit is $0$?

(a) $\tfrac13$
(b) $\tfrac25$
(c) $\tfrac12$
(d) $\tfrac35$

Show solution

The correct answer is (b) ★

The second output bit depends only on the second input bit, which is $0$ if $00$ was sent and $1$ if $11$ was sent. Over the channel a $0$ stays $0$ with probability $\tfrac45$, and a $1$ becomes $0$ with probability $\tfrac15$. By total probability, $\Pr(\text{second output bit}=0)=\tfrac13\cdot\tfrac45+\tfrac23\cdot\tfrac15=\tfrac{4}{15}+\tfrac{2}{15}=\tfrac25$.

Problem 2. A non-negative random variable $X$ takes the value $0$ with probability $1-q$ and the value $4$ with probability $q$. What upper bound does Markov's inequality give for the probability $\Pr(X\ge2)$?

(a) $\tfrac{q}{2}$
(b) $q$
(c) $2q$
(d) $4q$

Show solution

The correct answer is (c) ★

Since $X\ge0$, Markov's inequality applies: $\Pr(X\ge a)\le\mathbb{E}[X]/a$. Here $\mathbb{E}[X]=0\cdot(1-q)+4\cdot q=4q$, so with $a=2$ the bound is $\Pr(X\ge2)\le\tfrac{4q}{2}=2q$.

Problem 3. A prefix-free binary code is to be built with codeword lengths $1$, $2$, $3$, $4$, $5$, $6$ and $a$, where $a$ is a positive integer. What is the smallest value of $a$ for which such a code can exist?

(a) $4$
(b) $5$
(c) $6$
(d) $7$

Show solution

The correct answer is (c) ★

The Kraft inequality requires $\sum_i 2^{-\ell_i}\le1$. The six fixed lengths contribute $\sum_{k=1}^{6}2^{-k}=1-2^{-6}=\tfrac{63}{64}$, leaving a budget of $\tfrac1{64}=2^{-6}$. The extra codeword contributes $2^{-a}$, so we need $2^{-a}\le\tfrac1{64}$, that is $a\ge6$. The smallest such $a$ is $6$ (with $a=6$ the Kraft sum equals $1$ exactly).

Problem 4. A source emits five symbols with probabilities $\tfrac13$, $\tfrac13$, $\tfrac19$, $\tfrac19$ and $\tfrac19$. What is the average length of an optimal binary prefix-free code for this source?

(a) $2$
(b) $\tfrac{19}{9}$
(c) $\tfrac{20}{9}$
(d) $\tfrac73$

Show solution

The correct answer is (c) ★

Building the Huffman code: merge the two smallest probabilities ($\tfrac19+\tfrac19=\tfrac29$), then merge that node with the remaining $\tfrac19$ ($\tfrac29+\tfrac19=\tfrac13$), and finally merge the three resulting groups of probability $\tfrac13$. The codeword lengths are $2,2,2,3,3$, so the average length is $2\cdot\tfrac13+2\cdot\tfrac13+2\cdot\tfrac19+3\cdot\tfrac19+3\cdot\tfrac19=\tfrac43+\tfrac89=\tfrac{20}{9}$. It lies between the entropy $\tfrac43\log_2(3)$ and $\tfrac43\log_2(3)+1$.

Problem 5. A single bit is sent three times (a rate-$\tfrac13$ repetition code) over a binary symmetric channel that flips each bit independently with probability $p$, where $0<p<\tfrac12$. The receiver flags a possible error whenever the three received bits are not all equal. What is the probability that no error is flagged, that is, that the three received bits come out all equal?

(a) $(1-p)^3$
(b) $p^3$
(c) $(1-p)^3+p^3$
(d) $1-(1-p)^3-p^3$

Show solution

The correct answer is (c) ★

Whatever codeword is sent ($000$ or $111$), the three received bits are all equal in exactly two cases: none of the three bits flips, with probability $(1-p)^3$, or all three flip, with probability $p^3$. Hence the probability is $(1-p)^3+p^3$, the same for either transmitted bit.

Problem 6. A binary code, which is not linear, has three codewords: $111000$, $000110$ and $011011$. What is the minimum distance of this code?

(a) $2$
(b) $3$
(c) $4$
(d) $5$

Show solution

The correct answer is (b) ★

For a code that is not linear, the minimum distance is not the smallest codeword weight; it must be found by comparing all pairs of codewords. The three pairwise Hamming distances are $d(111000,000110)=5$, $d(111000,011011)=3$ and $d(000110,011011)=4$, so the minimum distance is $3$. (The smallest weight is $2$, from $000110$, but that is the distance to the all-zero word, which is not a codeword here.)

Problem 7. Let $X$ be a uniformly random bit, and let $Y$ be an independent bit that equals $1$ with probability $\tfrac14$. Let $Z=X\oplus Y$ be their exclusive-or (the sum modulo $2$). What is the mutual information $I(X;Z)$, in bits?

(a) $0$
(b) $\tfrac34\log_2 3-1$
(c) $2-\tfrac34\log_2 3$
(d) $1$

Show solution

The correct answer is (b) ★

Since $X$ is uniform and independent of $Y$, the output $Z=X\oplus Y$ is also uniform ($\Pr(Z=1)=\tfrac12\cdot\tfrac34+\tfrac12\cdot\tfrac14=\tfrac12$), so $H(Z)=1$ bit. Given $X=x$, $Z=x\oplus Y$ has the same distribution as $Y$, so $H(Z\mid X)=H(Y)=H(\tfrac14)=-\tfrac14\log_2\tfrac14-\tfrac34\log_2\tfrac34=2-\tfrac34\log_2 3$. Hence $I(X;Z)=H(Z)-H(Z\mid X)=1-\bigl(2-\tfrac34\log_2 3\bigr)=\tfrac34\log_2 3-1\approx0.19$ bits. Unlike a uniform $Y$, here $Y$ no longer masks $X$ completely, so $Z$ carries information about $X$.
